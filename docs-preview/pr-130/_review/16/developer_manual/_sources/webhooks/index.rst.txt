========
Webhooks
========

Webhooks allow an external system to react to LibreSign events without
replacing its own interface or repeatedly querying LibreSign. Native event
delivery is provided by Nextcloud's **Webhook Listeners** app. Each supported
event has its own reference page, including the point in the workflow that
triggers delivery and the data sent to the receiver.

**Availability:** upcoming LibreSign 16 **development** builds on Nextcloud
36, not a released stable LibreSign 16. Older LibreSign 13, 14, and 15 do
not provide this event. Confirm the installed revision before subscribing.

Native Nextcloud webhooks replace LibreSign's proprietary ``callback``
parameter and ``webhook_sign_url`` configuration in this development line.
The receiver must fetch signed PDFs independently with authorized credentials.
